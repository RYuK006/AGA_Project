Mathematical Reason for Dijkstra's Failure:

Dijkstra’s algorithm assumes that once a vertex u is extracted from the priority queue (marked visited), its distance label dist[u] is permanent and cannot be decreased by any subsequent path.

In Scenario A, node A is popped first with distance 3.0s (since 3.0 < 5.0). Dijkstra permanently finalizes A and relaxes A→H to 13.0s. Later, node B is processed. The edge B→A offers a green-wave credit of -4.0s (yielding 5.0 - 4.0 = 1.0s < 3.0s), but because A is already in the visited set, Dijkstra’s greedy invariant ignores this shorter route!

In contrast, Bellman-Ford performs (V - 1) full relaxation passes across all edges, allowing the negative credit to propagate to A in Pass 2 and onward to H in Pass 3, discovering the true global optimum (11.0s).

⚠ PASS V: NEGATIVE CYCLE CONFIRMED

In Pass 5, Bellman-Ford attempted further relaxation on cycle edge Z→X (-10.0s). Because the cycle sum is negative (4 + 4 - 10 = -2.0s < 0), shortest paths are undefined (−∞). The algorithm successfully caught and halted this unbounded condition!
